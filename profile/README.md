## Hi，你好 👋

欢迎来到 Uni Halo 团队！

我们致力于围绕 [Halo](https://halo.run/) 打造免费开源的 **uni-halo** 系列项目：一套源码，多端运行（小程序（推荐）、APP、H5），页面内容全部由配套插件动态配置，无需修改代码。

我们欢迎更多志同道合的朋友加入，也希望你可以在这里发现更多有意思的事情！

## ✨ 亮点功能

- **恋爱日记**：恋爱相册（支持查看密码，页内解锁）、恋爱清单、我们的故事；插件内置前台模板，任何主题零成本接入，管理员也可在移动端直接管理
- **登录管理**：账号密码登录、注册、微信一键登录与绑定，登录后下发 Halo 原生 PAT 令牌，内置登录限流与 RBAC 权限控制
- **动态配置**：横幅轮播、公告、友情链接（投稿审核 + 邮件通知）、应用信息与版本管理、维护模式等，全部在插件控制台完成
- **数据可视化**：站点数据看板、文章归档、标签、搜索、收藏、投票等内容模块一应俱全

## 🚀 快速开始

1. 安装插件：在 Halo 后台插件市场搜索「UniHalo」安装并启用；
2. 部署应用：参考 [官方文档](https://uni-halo-doc.ialley.cn) 下载 uni-halo 源码并本地运行；
3. 配置发布：在插件控制台完成内容与参数配置，发布上线。
